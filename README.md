# Veni Publishing website

Permanent structure:

- `/` — Veni Publishing
- `/kids/` — Veni Kids homepage and printed-book QR destination
- `/kids/animals/` — South African Animals & Biomes page

## GitHub Pages

1. Create a public repository named `venipublishing-website`.
2. Upload every item in this folder to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Confirm the temporary GitHub Pages site works.
7. In Settings > Pages, set the custom domain to `venipublishing.co.za`.
8. Configure xneelo DNS only after that.
9. Enable Enforce HTTPS once available.

Final QR destination: `https://venipublishing.co.za/kids/`
